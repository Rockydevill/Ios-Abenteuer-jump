# GBD STRATO Bridge

Dieser Branch ist ein reiner Transportkanal für Games Behind Doors.

- Keine GitHub Actions oder Runs.
- Keine Secrets oder Zugangsdaten.
- Work-Orders liegen ausschließlich AES-256-GCM-verschlüsselt vor.
- STRATO entschlüsselt lokal mit einem Schlüssel außerhalb des Webroots.
- Änderungen werden auf STRATO weiterhin nur nach Vorschau + Backup angewendet.
- Die Plattform wird dadurch nicht veröffentlicht und 0/3 bleibt unverändert.

Der normale iOS-Branch dieses Repositories wird von diesem Transportbranch nicht verändert.
